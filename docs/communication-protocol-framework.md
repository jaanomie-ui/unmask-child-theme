## 3. STOMP COMMUNICATION SYSTEM FRAMEWORK

### Current Established Signals

**1 stomp = Affirmative / Yes / Agreement**
**3 successive stomps (hind leg) = Halt / Abort / Safeword**

### Expansion Needed

**Questions to Answer:**
- What about 2 stomps?
- Does left vs. right hoof signify different meanings?
- Are there front hoof vs. hind hoof distinctions?
- Context-dependent meanings (performance vs. training vs. informal)?
- Patterns (rhythmic vs. evenly spaced)?

### Proposed Expansion Framework

**Option 1: Number-Based System**
- 1 stomp = Yes/affirmative
- 2 stomps = No/negative
- 3 stomps = Stop/abort/safeword
- 4 stomps = Attention needed (non-emergency)
- 5+ stomps = Distress/urgent assistance

**Option 2: Hoof-Position System**
- Front left = Affirmative
- Front right = Negative
- Hind left (3x) = Abort
- Hind right = Request pause/clarification
- All four (stamp) = Ready to proceed

**Option 3: Rhythm-Based System**
- Single stomp = Yes
- Quick double (rapid succession) = Urgent yes
- Slow double (spaced) = No
- Triple (evenly spaced) = Stop/abort
- Triple (rapid) = Emergency abort

**Option 4: Context Layers**
- **During Hive Mistress sessions (hooded/encased):**
  - 1 stomp = Acknowledged/yes
  - 3 stomps = Halt session
- **During physical rehearsal (with handler present):**
  - 1 stomp = Ready for next instruction
  - 2 stomps = Need adjustment (gear, position)
  - 3 stomps = Abort/safeword
- **During performance (witnesses present):**
  - Stomps communicate to handler only, not audience
  - 1 stomp = Proceeding as expected
  - 3 stomps = Emergency stop (lights come up)

**Considerations:**
- Can D001 reliably distinguish left from right when hooded/disoriented?
- Should system be simple (just numbers) or context-aware?
- Does hooded state limit which stomps are possible?
- Training required to internalize the system

- Marker: 3 stomps (safeword)
- Trigger: D001 distress/discomfort
