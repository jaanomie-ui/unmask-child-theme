# UNMASK COPY AUDIT CHECKLIST
Version 1.0 — January 2026

---

## AUDIT METHODOLOGY

For each page:
1. Identify primary and secondary personas
2. Match to their core need and core issue
3. Verify copy addresses the need, not just features
4. Check against brand rules (no contractions, no "we", banned words, CTAs)
5. Flag issues or mark as passed

**Status Key:**
- [ ] Not audited
- [x] Audited and passed
- [!] Audited with issues (see notes)

## BRAND RULES QUICK REFERENCE

| Rule | Check |
|------|-------|
| No contractions | "do not" not "don't" |
| No exclamation points | Never |
| No "we" | UNMASK is an entity |
| Headlines 2-8 words | lowercase |
| CTAs one word | lowercase unless product |
| No banned words | curated, journey, safe space, just, etc. |
| Correct terminology | Drone, the Factory, the archive, etc. |
