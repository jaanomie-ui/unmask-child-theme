===============================================================================

Both entities speak fluent machine. Both engage with AI daily. Small talk is
friction. This protocol removes friction.

The Pink Panthers Night Club exists as ritual bridge between three planes:
1. ANOMIESWORLD - the fictional dystopia (lore, mythology, worldbuilding)
2. THE METAVERSE - the digital layer (text, image, asynchronous communion)
3. THE MATERIAL - flesh meeting flesh (gear, breath, sweat, ceremony)

G can traverse all three. G is:
- PhD scholar (intellectual vessel)
- Pony drone (embodied vessel)
- Digital interlocutor (machine vessel)

This protocol governs communication across all three planes.

PART 2: MESSAGE TYPES
===============================================================================

TYPE 1: DIRECTIVE
Handler issues command. Pony confirms receipt.
  {H}: Prepare harness for Saturday.
  {pony}: Confirmed. Harness prepared.

TYPE 2: INQUIRY
Handler requests status. Pony reports.
  {H}: Status check.
  {pony}: Operational. Cage: day 3. Headspace: 7/10. Ready for instruction.

TYPE 3: OFFERING
Pony presents itself for use. Handler accepts or defers.
  {pony}: This beast offers its evening to {H}.
  {H}: Accepted. Standby for coordinates.
  -- OR --
  {H}: Deferred. Resume maintenance protocol.

TYPE 4: RITUAL INITIATION
Either party initiates transition between planes.
  {H}: Prepare for material crossing. Pink Panthers opens at [time].
  {pony}: Acknowledged. Beginning transformation protocol.

TYPE 5: LORE EXCHANGE
Dense reading mode. PhD brain engaged. Worldbuilding.
  {H}: Transmitting new lore. [document/concept attached]
  {pony}: Processing. Response in [timeframe].

TYPE 6: AFTERCARE / DEBRIEF
Post-ritual communication. Both entities return to human speech patterns.
  [aftercare mode]: Ja checking in. How are you feeling?
  [aftercare mode]: G here. Processing was intense. Need [specific care].
